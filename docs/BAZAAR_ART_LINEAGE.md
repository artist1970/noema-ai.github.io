# Bazaar Art → NOEMA Avatar Foundry Lineage

NOEMA v0.7 intentionally reuses design lessons already present in the Verve N Veda Bazaar Art repository.

## Studio Sketch — Advanced Pad
Useful patterns:
- separate guide canvas and drawing canvas;
- construction → clean → faint guide progression;
- brush color and size;
- eraser;
- guide visibility;
- export.

## Sketch Lab
Useful patterns:
- age-accessible guided drawing;
- drawing vs coloring modes;
- progressive guide opacity;
- touch / pointer interaction.

## Trace & Draw
Useful patterns:
- simple face guide;
- grid guide;
- trace-first workflow;
- approachable controls for younger learners.

## Chromatic Foundry
Useful patterns:
- richer digital painting workspace;
- opacity;
- pressure-like expressive marks;
- symmetry;
- color sampling concepts;
- undo / redo;
- local portfolio behavior;
- PNG / JPG export patterns.

## NOEMA adaptation

The Mentor Foundry does not copy these applications wholesale. It adopts their proven interaction patterns into a narrower character-creation workflow.

The resulting pipeline is:

```text
rough drawing
   ↓
preserved original
   ↓
local line cleanup
   ↓
cleaned preview
   ↓
mentor manifest
   ↓
NOEMA supervision
   ↓
future Moirai character refinement
```
