# Public Presentation Compatibility

`front/public-presentation.js` is retained temporarily.

Its purpose is to sanitize older NAIB-compatible interfaces that still instantiate the internal runtime directly.

It is **not** the canonical public front.

Canonical public front:
`https://artist1970.github.io/NAIB.github.io/`

Do not delete this compatibility layer until legacy entry points and runtime integrations have been verified against the new NAIB public front.
