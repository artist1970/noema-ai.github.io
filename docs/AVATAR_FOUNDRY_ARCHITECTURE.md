# NOEMA Avatar Foundry v0.7

The Avatar Foundry creates a persistent mentor identity for any supported age or learning stage.

## Two creation paths

### Build My Mentor
Structured controls:
- mentor name;
- hair style and color;
- eye color;
- visual skin-tone palette;
- outfit style;
- clothing colors;
- temperament;
- mentor traits;
- shared interests;
- collaboration preferences;
- browser voice profile.

### Draw My Mentor
A user may create the mentor from a rough drawing.

The drawing is treated as **creative intent**, not as a finished illustration and not as a psychological test.

The local studio supports:
- separate guide and drawing canvases;
- face, figure and grid guides;
- three guide-strength levels;
- brush size;
- color;
- opacity;
- eraser;
- undo / redo;
- symmetry assist;
- reversible line cleanup;
- original-vs-cleaned preview;
- local preservation of both versions.

## Cleanup

Local cleanup:
1. removes tiny accidental strokes;
2. averages jitter;
3. simplifies redundant points;
4. applies curve smoothing;
5. preserves color, opacity and broad character shape.

This is geometric line cleanup, not an AI image generator.

## Future Moirai refinement

A future image service may receive:
- the untouched original sketch;
- the locally cleaned sketch;
- the mentor manifest;
- a strict preserve-source-identity instruction.

It must not silently replace the user's character with an unrelated generated face.

## Inference boundary

Neither structured appearance nor a hand drawing is used to infer:
- race or ethnicity;
- intelligence or ability;
- personality of the student;
- disciplinary risk;
- politics;
- religion;
- socioeconomic status;
- psychological condition.

Mentor character choices tell NOEMA how the user wants the mentor to look or work with them, not who the user "is."
