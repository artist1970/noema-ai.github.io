# NOEMA v1.0 — Integrated Intelligence

v1.0 teaches NOEMA to coordinate the systems already under her governance.

## Principle

> Plan visibly. Execute only what is actually connected. Mark handoffs honestly. Synthesize under NOEMA policy.

## Flow

```text
User request
   ↓
NOEMA route
   ↓
research requirement
   ↓
task planner
   ↓
dependency graph
   ↓
specialist eligibility
   ├─ local integrated → execute bounded local function
   ├─ handoff-ready → prepare handoff, mark not executed
   ├─ restricted → block or mark unavailable
   └─ unknown → unavailable
   ↓
provider request receives settled specialist context
   ↓
provider response
   ↓
NOEMA integrated synthesis
```

## Local integrated specialists

- The Verifier: verification state and evidence requirements.
- Khaemenes Mentor: learning/mentor presentation adaptation.
- Sovereign Agent layer: bounded decision frame.

These local outputs do not create external side effects.

## Handoff-ready specialists

- Moirai
- PROSE
- ARSHIF
- PLERA Search
- Hope when explicitly requested

A handoff is not execution.

The UI and provider context both preserve that distinction.

## Restricted systems

333 Network remains account-dependent.

Account or communications functionality does not become available merely because task planning references it.
