# International Source Diversity Policy

For significant international or politically contested current-event claims, the Verifier should avoid treating one national information market as sufficient.

Where relevant it should seek reporting from multiple geographic families, for example:
- global wire services;
- North America;
- Europe;
- Middle East;
- Africa;
- Asia;
- Latin America;
- Oceania.

Geographic diversity does not mean all sources are equally reliable.

The Verifier still evaluates:
- source provenance;
- original reporting vs repetition;
- institutional ownership;
- access to primary records;
- corrections;
- date;
- named evidence;
- conflicts of interest;
- independent corroboration.

Different viewpoints are not manufactured into false equivalence. When evidence is asymmetric, the evidence status should say so.
