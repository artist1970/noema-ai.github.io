# NOEMA v0.8 — The Verifier Agent

## Purpose

The Verifier Agent is a research-governance layer beneath NOEMA.

It exists to reduce:
- confirmation bias;
- search-ranking bias;
- single-source dependence;
- duplicated wire/reporting dependence;
- stale claims;
- fact/opinion confusion;
- unsupported certainty.

It does **not** claim that an algorithm can eliminate all human or institutional bias.

Instead it makes the evidence process explicit and auditable.

## Non-negotiable rule

> Search-engine ranking is discovery, not verification.

A result being first, popular, repeated, or highly linked does not make it true.

## Evidence ladder

Before a meaningful claim can receive `verified-fact` status, the Verifier checks:

1. factual claim definition;
2. ARSHIF archive/context search;
3. Khaemenes educational-portal context search;
4. primary or official evidence;
5. independent corroboration;
6. domain-specific lane when applicable;
7. international/geographic comparison when relevant;
8. freshness;
9. active search for contradiction;
10. evidence matrix;
11. verdict gate.

## Evidence statuses

```text
verified-fact
strongly-supported
partially-supported
disputed
contradicted
inconclusive
outdated
unexamined
```

`verified-fact` is intentionally difficult to reach.

## Ecosystem evidence lanes

- ARSHIF: archives, history, context, source literacy.
- Khaemenes: educational and curriculum context.
- The Verifier: current events, international reporting, media/source comparison.
- Medicament: medical and health research.
- Firmament: law, official legal authority, public records.
- Solanar: weather, atmospheric observations, satellite, space weather.
- Evidence & Citation Studio: claims, provenance, evidence relationships.

None of these is a privileged truth oracle.

Each is a research lane.

## Source independence

Ten articles derived from one wire report are not ten independent confirmations.

The Verifier therefore groups evidence by:
- publisher;
- organization;
- parent organization;
- wire service;
- explicit independence family.

## Contradiction requirement

The workflow explicitly asks:

> What credible evidence would make this claim false, incomplete, or materially different?

This prevents a verification search from becoming a search for agreement.

## Current static-release limitation

v0.8 contains the Verifier policy, task engine, evidence matrix and local research console.

It does not falsely claim that GitHub Pages can autonomously search all external sources.

Live retrieval is reserved for a future approved provider/server connector.
