# Learning Resource Types

The federation supports:

```text
lesson
course
practice
quiz
game
workshop
simulator
tool
reference
archive
portal
resource
```

Each resource may also carry:

```text
subjects
learningObjectives
learningValue
curricularWeight
highStakesDomain
```

Learning values:

```text
core
practice
supplemental
extension
recreational
unknown
```

Unknown is intentional.

NOEMA may preserve uncertainty instead of inventing educational purpose.
