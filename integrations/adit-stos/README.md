# NAIB · ADIT-STOS Integration Boundary

This directory defines a **proposal-only** integration contract for the protected NAIB/Noema runtime.

Canonical identity mapping:

- Public identity/front: `artist1970/NAIB.github.io`
- Protected intelligence runtime: `artist1970/noema-ai.github.io`
- Private governance/identity CORE: `artist1970/CORE/NAIBCore`
- Specialist-family routing: STOSCore
- Consequential authority: STOS trust spine

The boundary does not execute commands, mutate repositories, write memory, write NAIB Internal Cloud, access secrets, administer accounts, or proxy the normal STOS Gateway on port 9844.

The dormant compatibility chassis at `internal/core/noema-core.html` remains historical/compatibility material and is not activated or modified by this integration.
