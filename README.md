# NOEMA
## Sovereign Adult Intelligence

**NOEMA** is the adult AI presence and orchestration intelligence of the Verve N Veda / PLERA ecosystem.

NOEMA has her own identity, conversational architecture, context, preferences, continuity, reasoning interface, safety boundaries, and relationship to the wider ecosystem.

She does **not** duplicate specialist systems.

- **Hope** — legacy companion / Codex lineage and a distinct conversational archive
- **Moirai** — visual imagination and image-generation module
- **Khaemenes Mentor Core** — family, learning, resource, permissions, and policy intelligence
- **Sovereign Problem-Solving Agent** — constrained ranking and adaptive decision support
- **PROSE** — writing and editing
- **ARSHIF** — archives and knowledge
- **The Verifier / PLERA Search** — research pathways
- **333 Network** — account-aware communication services

## Foundational principle

> Noema is an intelligence with access to specialist modules, not a wrapper around them.

## v0.2 foundation

This repository establishes:

- Noema identity and persona layer;
- adult-first conversation shell;
- mode and intent routing;
- local preferences;
- bounded local conversation continuity;
- module registry and handoff adapters;
- high-stakes and privacy boundaries;
- Mentor Core integration hooks;
- Sovereign Agent integration hooks;
- Hope and Moirai relationship definitions;
- installable/offline-capable GitHub Pages shell;
- root `mentor-manifest.json` for the central Mentor ecosystem registry;
- automated tests.

The repository deliberately does **not** contain an embedded API key or pretend that a language model is already connected. Model-provider integration is a separate backend/provider phase.
