## Preserved cloud boundaries

The live IndexedDB-backed NAIB Internal Cloud (`naib_internal_cloud_v1`) remains part of the protected runtime. ADIT does not receive direct write authority to it.

The older `internal/core/noema-core.html` / `nmc_v1` Mini-AGI chassis remains dormant compatibility material. This update does not activate, rewrite, import, or route traffic through it.

## Public/runtime split

The root `index.html` remains a neutral navigation gateway. It is not the canonical NAIB interface. Public visitors are routed to `artist1970/NAIB.github.io`; protected runtime modules remain in this repository.

## Authority rule

No NAIB, Noema, specialist, model, memory, cloud, or ADIT response grants STOS execution authority.
