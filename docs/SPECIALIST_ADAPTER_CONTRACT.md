# Specialist Adapter Contract

Every runtime specialist adapter exposes:

```text
id
name
version
capabilities
availability
canExecute()
prepare()
execute()
```

This provides one interface for future PROSE, Moirai, school-level Khaemenes, Solanar, Firmament, Medicament, 333, and other adapters.

An adapter's existence does not grant permission.

NOEMA's capability ledger and specialist eligibility remain authoritative.
