# NOEMA Project Context

Project Context gives NOEMA a stable working frame without turning every project detail into personal long-term memory.

A project contains:

- name;
- summary;
- primary mode;
- status;
- tags;
- created/updated timestamps.

One project may be active at a time.

The active project is supplied to the context builder and also helps rank relevant Memory Library entries.

Examples:

```text
NOEMA
Mathematics
Khaemenes High School
Preschool Mentor
Verve N Veda landing pages
```

Project Context is stored locally under the NOEMA namespace and can be removed independently.
