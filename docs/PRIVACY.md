# NOEMA Privacy Baseline

NOEMA v0.2 is local-first.

The static shell:
- requires no account;
- contains no analytics;
- contains no advertising;
- contains no tracking pixel;
- contains no embedded API credential;
- stores only namespaced local preferences and bounded conversation continuity.

Users may clear NOEMA's local data without affecting other applications.

Future provider/back-end integrations must clearly disclose:
- what information leaves the browser;
- which provider receives it;
- whether the provider stores it;
- whether account authentication is required.
