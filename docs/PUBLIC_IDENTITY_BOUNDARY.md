# Public Identity Boundary

## NAIB

Front-facing intelligence.

NAIB owns:
- the public name;
- conversation presentation;
- user-facing orchestration;
- visible task plans;
- specialist handoff presentation;
- voice interface.

## NOEMA

Administrative intelligence.

NOEMA owns:
- Constitution;
- capability ledger;
- action gates;
- Memory Library governance;
- identity and guardian pathways;
- Verifier evidence rules;
- specialist eligibility;
- security;
- provider boundaries;
- account/server seams.

## Rule

NAIB may ask NOEMA for a governed capability.

NAIB may not become NOEMA.
