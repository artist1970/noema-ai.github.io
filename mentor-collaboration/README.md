# Mentor Collaboration Laboratory — fictional, review-only v1

The local laboratory composes existing NOEMA/NAIB mentor-discovery, consented-handoff and approved-public-knowledge-reference modules. It is NOT a live service, model, authenticated host or an STOS terminal. Both adult and student actors are fictional. Its source-only callbacks simulate authentication and consent; they do not create real approval, a signed consent receipt or guardian verification.

Run: `node mentor-collaboration/run-fictional-lab.mjs` and `node --test tests/mentor-collaboration-lab-v1.test.mjs`.

The lab rehearses Archaemenes -> Zelle: an adult consent preview plus one source-attributed Eiren public Q&A record, and a minor preview with simulated guardian approval but NO adult-only Q&A. It also revokes a fictional Archaemenes -> Eiren proposal and confirms that replay is withheld. At most three unique cited public references can be included in an adult capsule. All sources remain statements, not independently verified truths.

A single previously published Eiren record is pinned in a test-only fixture with its source file Git blob SHA. The fixture is NOT an editorial approval or an independent verification of current source contents; the Creative Spark nine-source federation remains canonical. Its 900 capsule drafts remain unpublished. No private CORE or learner data is imported.

The capsule contains only curated subject objective, target mentor and optional public citations; there is no principal, prior turn, transcript, guardian document or student profile. The introduction remains unwritten: the recipient never received or generated a reply.

The Creative Spark receiving adapter is separately tested in its private repository. Separate CI green checks are not authenticated cross-repository communications. Before real student handoffs: independently authenticated host, guardian account binding, recipient identity, replay and revocation across devices, consent audit receipts, record-level age review and real acceptance tests are still required. NOEMA remains Chancellor; NAIB remains administrator.
